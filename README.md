# Atividade Avaliativa Individual 01

Seis sistemas em JavaScript puro (HTML, CSS e JS), cada um simulando um processo de negócio com cadastro em loop, validação de dados e relatório final consolidado.

## Exercícios

1. Frete com múltiplos pedidos
2. Folha de pagamento
3. Controle de produção e estoque
4. Reservas de hotel
5. Treinos esportivos
6. Vendas e comissões

## Tecnologias

HTML5 · CSS3 · JavaScript (DOM, arrays, objetos)

## Como rodar

Acesse online: https://ninaduquehc.github.io/DesenvolvimentoWeb2_Atividade1/

Ou localmente: abra o `index.html` no navegador (ou use uma extensão tipo Live Server).
